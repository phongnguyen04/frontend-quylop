# Frontend Quản Lý Lớp Học Blockchain

## Giới thiệu

Dự án frontend xây dựng bằng React + Vite dùng để tương tác với Smart Contract trên Ethereum.

## Công nghệ sử dụng

- ReactJS
- Vite
- Ethers.js
- TailwindCSS
- Solidity
- MetaMask

## Chức năng

- Kết nối ví MetaMask
- Hiển thị thông tin lớp học
- Quản lý sinh viên
- Tương tác Smart Contract

## Cài đặt

```bash
npm install
npm run dev
